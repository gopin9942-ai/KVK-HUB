Live microphone glowing bar test

இது தனி test page. Microphone audio-வை எங்கும் அனுப்பாது, பதிவு செய்யாது, playback செய்யாது. Mic level-ஐ local-ஆக மட்டும் அளந்து கீழே உள்ள glowing bar-ஐ இயக்கும். ஏற்கெனவே voice room call நடக்கும்போது இதைத் தொட வேண்டாம்; முதலில் call-ஐ விட்டு வெளியேறி test செய்யவும்.

Start Test அழுத்தி microphone permission கொடுக்கவும்.

Sensitivity-ஐக் குறைத்தால் மெதுவான குரலுக்கும் bar அசையும். அதிகரித்தால் background noise குறைவாகப் பிரதிபலிக்கும்.

Test steps

  1. Start Test அழுத்தவும்.
  2. பேசும்போது bar நீளமாகி பிரகாசமாகிறதா பாருங்கள்.
  3. சத்தமாகப் பேசும்போது bar அதிகமாகவும், மெதுவாகப் பேசும்போது குறைவாகவும் அசைய வேண்டும்.
  4. பேசுவதை நிறுத்தினால் bar மீண்டும் பூஜ்ஜியத்துக்கு வர வேண்டும்.
  5. Stop அழுத்தி microphone-ஐ release செய்யவும்.
