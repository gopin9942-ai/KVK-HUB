Test steps

  1. Start Test அழுத்தவும்.
  2. சாதாரணமாகப் பேசவும்; பேசும்போது avatar சுற்றி பச்சை glow மற்றும் SPEAKING badge வர வேண்டும்.
  3. பேசுவதை நிறுத்தினால் சுமார் அரை விநாடிக்குள் glow மறைய வேண்டும்.
  4. மெதுவாகவும் சத்தமாகவும் பேசிப் பாருங்கள். தேவையானால் sensitivity slider மாற்றவும்.
  5. Stop அழுத்தி microphone-ஐ release செய்யவும்.
